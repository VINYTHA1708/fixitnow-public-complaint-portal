# FixItNow – Public Complaint Portal

FixItNow is a web-based complaint management system that allows users to raise, track, and manage public complaints efficiently. The goal of this project is to provide a simple and transparent platform for reporting issues and resolving them in an organized way.

## 🚀 Features

- User registration and login
- Raise complaints with required details
- Track complaint status
- Admin can view and update complaints
- Structured complaint handling system
- Simple and user-friendly interface

## 🧑‍💻 Tech Stack

**Backend:**
- Java
- Spring Boot

**Database:**
- MySQL 

**Frontend:**
- HTML/CSS 

**Other Tools:**
- Git & GitHub
- REST APIs

## 📌 How it Works

1. User registers and logs into the system  
2. User submits a complaint  
3. Complaint is stored in the database  
4. Admin reviews and updates the complaint status  
5. User can track the complaint progress  

This system helps in making complaint handling more efficient and transparent.

## ⚙️ Installation & Setup

1. Clone the repository  
   git clone https://github.com/VINYTHA1708/fixitnow-public-complaint-portal.git  

2. Navigate to the project folder  
   cd fixitnow-public-complaint-portal  

3. Configure database in `application.properties`  

4. Run the application  
   mvn spring-boot:run
